DICE ROLLER V4 — PWA

Arquivos:
- index.html
- manifest.json
- service-worker.js
- icons/icon-192.png
- icons/icon-512.png

O que foi adicionado:
- PWA instalável
- ícone do aplicativo
- modo standalone (sem barra normal do navegador após instalar)
- Service Worker com cache/offline
- botão "Instalar no celular" quando o navegador disponibilizar o prompt
- preservados os recursos da V3: dados D4–D100, histórico, cores, vibração e configurações salvas

IMPORTANTE:
Abrir index.html diretamente como arquivo (file://) não é suficiente para instalar como PWA.
Para instalação, publique a pasta em HTTPS. Para teste local, também pode ser servido por localhost.

A instalação e o menu disponível dependem do navegador/dispositivo.
